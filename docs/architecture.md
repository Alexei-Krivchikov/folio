# Architecture — folio

> Live doc. Update on every structural change. Inspired by `habits-tracker/ARCHITECTURE.md`.

## Goal

Creative portfolio/lab to impress recruiter. MVP = static Next.js, no DB/API, EN, free hosting. Show 3 projects (1-2 commercial as "Commercial — Role/Stack/Impact" + 1-2 personal like habits-tracker).

Refs: tajmirul.site, vikasdev-in.vercel.app — dark premium, Tailwind, Motion.

## Monorepo

- **Manager:** pnpm 11 workspaces (`pnpm-workspace.yaml`)
- **Orchestrator:** Turborepo 2 (`turbo.json` — tasks: build/dev/lint/typecheck)
- **Tooling:** Biome 2 (lint/format, `biome.json` at root), TypeScript 5 strict (`tsconfig.base.json`)
- **Deploys:** Vercel Hobby, Git integration with Root Directory `apps/web`, at `alexei-krivchikov.vercel.app` (ADR 0005)

Phase 2: add PG + Drizzle + Route Handlers for guestbook/views (opt-in).

## packages/ui

Ember tokens in `src/tailwind.css` (background, foreground, muted, accent with gradient ends, border, radii, the `marquee` keyframe) and the primitives `Button`, `AccentText`, `Grain`, `HudLabel`, `LocalTime`, `MagneticButton`, `Marquee`, `ScrollProgress`, `SectionHeading`, `TiltCard`, `WordReveal`, plus `usePointerMotion` and `cn`.

## Styling & Animation

- Tailwind 4 + shadcn-style primitives (cva + tailwind-merge). Ember palette as CSS variables in `packages/ui/src/tailwind.css`; the site is dark only
- Three fonts through `next/font/google`: Bricolage Grotesque (sans), Geist Mono (mono), Instrument Serif italic (serif accent)
- Motion 13 for reveals, cards and hover; Lenis for smooth scroll. GSAP/R3F stay reserved for `app/lab` (phase 2)
- Hero Signature moment: an `ogl` fragment shader (`components/hero/hero-shader.tsx`), a separate chunk imported dynamically after first paint (`lib/after-first-paint.ts`). Until it runs, and whenever it cannot (reduced motion, no WebGL2, weak device, failed load, no JavaScript), the Poster is shown
- Case study navigation: React `ViewTransition` morphs the card cover into the Case study cover (ADR 0006); disabled under `prefers-reduced-motion`
- OG images and icons are generated by `next/og` (ADR 0004). `next/og` cannot load web fonts by itself, so the display font is read from `apps/web/assets/fonts` through `lib/og-fonts.ts`, and `next.config.ts` includes that folder in file tracing. `public/` stays Project screenshots only
- CI: `lighthouse.yml` builds the site and runs Lighthouse CI on `/` and `/projects/folio` (mobile, simulated slow 4G, 3 runs); the median goes to the job summary. It reports and never fails on scores

## Conventions

- Imports via `@/*` (web) and `@folio/*` (packages)
- Commits: conventional (`feat:`, `fix:`, `docs:`)
- Specs: `docs/specs/00X-<slug>/spec.md` per feature (tickets in `issues/`), ADR for stack decisions
