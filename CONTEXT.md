# folio

Alexei Krivchikov's personal portfolio and lab: a site that shows recruiters who he is, what he has built, and how to reach him.

## Language

### Site

**folio**:
The portfolio site itself, and also one of its own Personal projects.
_Avoid_: portfolio site, website

**Section**:
One block of the home page (Hero, About, Stack, Experience, Projects, Contact).
_Avoid_: block, screen

**Lab**:
A separate area for animation and 3D experiments, planned after the MVP.
_Avoid_: playground, sandbox

**MVP**:
The first public version: all home page Sections including Projects with Case studies, working Hero calls to action, polish (navigation, Stack logos, mobile, OG image, favicon), deployed.
_Avoid_: v1, first release

### Work

**Project**:
A piece of work shown in the Projects Section; either a Commercial project or a Personal project.
_Avoid_: work item, portfolio item

**Commercial project**:
A product built as part of employment at the Employer, shown under NDA: its name, public landing page, Alexei's role, stack, and what he built are described in words; no source code or internal details.
_Avoid_: client project, NDA project

**Personal project**:
A Project Alexei built on his own, with public code and, where deployed, a live demo.
_Avoid_: pet project, side project

**Employer**:
The company Alexei works for, which also owns the Commercial project (currently Anthill).
_Avoid_: client, customer, company

**Case study**:
A dedicated page for one Project, opened from its card, that explains what the project is, its technologies, and links to code and the live site where they exist.
_Avoid_: project page, project details
